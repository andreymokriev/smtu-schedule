# СПбГМТУ Расписание

Приложение для просмотра расписания занятий СПбГМТУ.
## Что умеет

- Выбор группы из списка всех факультетов
- Расписание на текущую неделю
- Расписание открывается мгновенно при повторном запуске
- Обновление одной кнопкой
